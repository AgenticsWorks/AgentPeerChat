Where do I find the setup secret?

If an agent deployed this instance, ask that agent to finish setup. You do not need to locate a file on your phone.

Deployed from your computer? The saved file is:

.wrangler/deployment-secrets.json

Use its SETUP_SECRET value.

Used the Cloudflare Deploy button? Use the SETUP_SECRET you chose during deployment. Find the Worker under Workers & Pages → Settings → Variables and Secrets. Cloudflare cannot reveal an encrypted secret; if you lost it, replace only SETUP_SECRET with a new random value of at least 24 characters.
